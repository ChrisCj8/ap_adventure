<p>The Bind Menu lets you set binds specific to this gamemode, so you can set up binds for apAdventure without having to sacrifice bind space for other gamemodes.</p>
<p>To add a bind, select a preset from the dropdown in the top right of this window and then click on the button left of the dropdown and press the key you want to bind it to. After that, click either the "Add Run Bind" or "Add Global Bind" button depending on if you want the bind to only apply for this run or always be active when you're playing this gamemode. You can then make further edits to the preset from there.</p>
<p>The button labeled "Manage Run Bind Data" opens a window you can use to delete bind data from past runs. You should check up on this window to delete some old bind data once in a while.</p>
<p>You can use the console commands "apadv_resetglobalbinds" and "apadv_resetrunbinds" to reset your binds in case you accidentally bind a key in a way that prevents you from accessing this menu again.</p>
